## 📄 Sobre o Projeto

Este é um projeto de controle financeiro pessoal, desenvolvido com **HTML**, **CSS** e **JavaScript puro**. O sistema permite ao usuário adicionar, visualizar e remover transações de forma simples e intuitiva. Os dados são armazenados no **localStorage** do navegador, garantindo a persistência das informações mesmo após recarregar a página.

É um projeto ideal para demonstrar habilidades em manipulação direta do DOM, gerenciamento de estado local e lógica de programação.

## 🚀 Tecnologias Utilizadas

- **HTML5:** Para a estrutura semântica da aplicação.
- **CSS3:** Para a estilização moderna e responsiva do layout.
- **JavaScript (Vanilla JS):** Para toda a lógica funcional da aplicação, incluindo a manipulação do DOM e eventos.
- **LocalStorage:** Para armazenar os dados das transações diretamente no navegador do usuário.

## 📌 Funcionalidades

- ✅ Adicionar novas transações com descrição, valor e data.
- ✅ Excluir transações individualmente da lista.
- ✅ Cálculo automático e em tempo real do total de entradas, saídas e saldo geral.
- ✅ Interface atualizada dinamicamente a cada nova transação ou exclusão.
- ✅ Persistência de dados, mantendo as informações salvas entre as sessões.
- ✅ Layout responsivo, adaptado para uso em diferentes dispositivos.

## 🧪 Como rodar o projeto localmente

1.  **Clone o repositório:**
    ```bash
    git clone [https://github.com/leandrowork03/controle-de-gastos.git](https://github.com/leandrowork03/controle-de-gastos.git)
    ```
2.  **Acesse a pasta:**
    ```bash
    cd controle-de-gastos
    ```
3.  **Abra o arquivo:**
    Abra o arquivo `index.html` em seu navegador de preferência. O projeto é estático e não precisa de um servidor local para funcionar.
