# 💸 Sistema de Controle de Gastos

Projeto de controle financeiro pessoal desenvolvido com **HTML**, **CSS** e **JavaScript puro**.  
Permite adicionar, visualizar e remover transações, com cálculo automático de saldo, receitas e despesas.  
Os dados são armazenados no **localStorage**, garantindo persistência mesmo após recarregar a página.

---

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- LocalStorage

---

## 📌 Funcionalidades

- ✅ Adicionar transações com descrição, valor e data
- ✅ Excluir transações individualmente
- ✅ Cálculo automático de entradas, saídas e saldo total
- ✅ Interface atualizada dinamicamente
- ✅ Persistência de dados com localStorage
- ✅ Layout responsivo para diferentes dispositivos
